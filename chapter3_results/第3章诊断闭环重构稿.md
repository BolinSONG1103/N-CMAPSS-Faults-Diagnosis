# 第3章 物理结构约束的航空发动机部件健康诊断方法

> 本稿对应诊断闭环 v2。正式数值已从锁定 CSV/JSON 汇总；任何后续方法改动均须建立新版本实验，不得覆盖本稿中的失败项。

## 3.1 引言

航空发动机气路部件退化会引起转速、温度、压力及燃油流量等多源测量的协同变化。然而，飞行高度、马赫数、环境状态和推力指令同样会显著改变传感器响应，使工况变化与部件退化在测量空间中相互叠加。仅利用原始测量进行端到端分类，虽然能够输出故障标签，但难以回答部件性能下降幅度、退化演化趋势及诊断结果是否满足发动机退化先验等问题。

针对上述问题，本章提出一种物理结构约束的航空发动机部件健康诊断方法。首先，利用相似参数修正和健康基准模型消除主要工况影响，形成标准化气路残差；其次，利用 N-CMAPSS 连续健康参数辨识传感器—部件影响矩阵，将故障诊断转化为病态线性反问题；再次，通过非正与单调重参数化，把不可逆退化先验作为解空间硬约束并进行正则化反演；最后，在连续健康参数估计基础上建立故障检测、多部件隔离、有序退化等级和未知故障拒识，形成从传感器异常到部件级健康状态的完整诊断闭环。

与以 PBM+DTAE 为代表的“性能基准—残差—分类”方法相比，本章不直接以离散类别作为唯一输出，而是首先估计具有明确部件含义的连续效率及流量退化量，再由统一决策层形成检测、隔离和退化等级。连续健康参数能够为后续剩余寿命预测提供状态输入，从而连接故障诊断与寿命预测两个研究环节。

本章主要工作包括：

1. 建立只使用推力指令、马赫数和入口相似参数的健康基准，避免将受退化影响的转速量作为基准自变量；
2. 构造量程归一化的传感器—部件影响矩阵，并从奇异谱、列夹角和弱可辨识方向分析反问题病态性；
3. 提出非正—单调硬约束与 Tikhonov 收缩相结合的连续健康参数反演方法；
4. 建立以标定机队健康分布为依据的多标签诊断决策和数据定义的有序退化等级；
5. 采用发动机单元完全隔离、未见故障组合及留一故障族实验，验证方法的连续估计、检测隔离、阶段识别和未知故障拒识能力。

## 3.2 问题描述与总体框架

### 3.2.1 数据变量与诊断目标

设第 u 台发动机在第 t 个飞行循环、工况采样点 k 的工况变量、气路测量和部件健康参数分别为

\[
\boldsymbol w_{u,t,k}\in\mathbb R^4,\qquad
\boldsymbol x_{u,t,k}\in\mathbb R^{13},\qquad
\boldsymbol\theta_{u,t}\in\mathbb R^9.
\]

其中，工况变量由推力杆角度 TRA、马赫数 Mach、入口温度相似参数和入口压力相似参数构成。九维健康参数包括 HPT 效率、Fan 效率与流量、HPC 效率与流量、LPT 效率与流量以及 LPC 效率与流量。由于当前数据辨识链未包含 HPT 流量参数，本章不宣称覆盖完整十维健康参数空间。

诊断闭环输出包括：连续健康参数估计 \(\hat{\boldsymbol\theta}_{u,t}\)、发动机故障状态 \(\hat y^{det}_{u,t}\)、九维部件多标签 \(\hat{\boldsymbol y}^{iso}_{u,t}\)、有序退化等级 \(\hat g_{u,t}\) 和未知故障标志 \(\hat y^{unk}_{u,t}\)。

### 3.2.2 离线辨识与在线诊断

总体框架由离线辨识和在线诊断两部分组成。离线阶段仅使用训练发动机，完成健康基准、健康残差尺度和影响矩阵辨识；标定发动机用于选择正则化参数、诊断阈值、持续周期数、有序等级模型和拒识阈值。在线阶段只需要当前及历史气路残差，不读取真实健康参数、未来寿命或测试发动机终点状态。

图3-1应由作者手绘，至少区分以下信息流：训练可见真值 T、在线可见的 W/X、训练单元、标定单元、测试单元，以及连续估计、离散诊断和未知拒识三个输出分支。

## 3.3 工况修正与健康基准残差

### 3.3.1 相似参数修正

以训练机队健康样本的入口温度和压力中位数作为全局参考 \(T_{ref}\) 与 \(P_{ref}\)，定义

\[
\theta_c=\frac{T_2}{T_{ref}},\qquad
\delta_c=\frac{P_2}{P_{ref}}.
\]

转速、燃油流量、温度与压力测量分别按照温度平方根、压力比及入口归一化关系进行修正。修正后的十三维测量包括 \(N_{f,c}\)、\(N_{c,c}\)、\(W_{f,c}\)、四个温度比和六个压力比。相似修正的目的不是完全消除工况影响，而是降低不同飞行包线下测量尺度的系统漂移，为后续健康基准学习建立一致输入空间。

### 3.3.2 健康基准模型

对第 j 个修正测量建立健康基准函数

\[
\hat x^{(0)}_j=f_j(TRA,Mach,\theta_c,\delta_c).
\]

基准模型采用 HistGradientBoostingRegressor。输入中不包含 Nf 或 Nc，原因是转速本身会受到部件退化影响，若将其作为健康基准自变量，可能形成“退化变量解释退化响应”的信息回路。健康残差定义为

\[
r_j=\frac{x_j-\hat x^{(0)}_j}{\sigma^{(0)}_j},
\]

其中 \(\sigma^{(0)}_j\) 仅由训练发动机健康残差计算。每台发动机前三个循环的同工况窗口均值用于消除制造差异和未知初始磨损引起的单元偏置。

健康基准的正式证据不能只展示单台发动机拟合散点，还应报告训练外发动机的逐单元误差、残差中心漂移和工况相关性。对应数据与图：正式运行后由健康基准泛化实验生成。

## 3.4 影响矩阵辨识与可辨识性

### 3.4.1 线性化部件影响关系

在局部退化范围内，将标准化残差表示为

\[
\boldsymbol r(t)=\boldsymbol H\boldsymbol\theta(t)+\boldsymbol\varepsilon(t),
\]

其中 \(\boldsymbol H\in\mathbb R^{13\times9}\) 描述部件效率或流量变化在气路测量中的响应方向。H 由训练发动机的连续健康参数监督辨识，因此属于数据辨识的物理结构映射，而不是由完整部件特性图直接推导的第一性原理模型。

为避免不同健康参数量程造成正则化含义不一致，引入训练数据量程矩阵 \(\boldsymbol S\)，得到

\[
\boldsymbol H_n=\boldsymbol H\boldsymbol S,qquad
\tilde{\boldsymbol\theta}=\boldsymbol S^{-1}\boldsymbol\theta.
\]

### 3.4.2 病态性分析

正式分析至少包括：Hn 热图、奇异值谱、列向量夹角、最小奇异值对应的右奇异向量，以及按发动机单元 bootstrap 得到的矩阵列稳定性。条件数只能说明整体病态程度，最弱右奇异向量才能解释哪些部件健康参数容易发生混叠。

如果重构后的训练划分使条件数偏离旧版 1562.8，不应强制恢复旧指纹。旧指纹使用了全部 dev 单元；v2 的条件数应由训练单元重新估计并据实报告。

## 3.5 非正—单调约束的健康参数反演

### 3.5.1 无约束基线

逐循环 Tikhonov 基线为

\[
\hat{\boldsymbol\theta}_B(t)=
\arg\min_{\boldsymbol\theta}
\left\|\boldsymbol H_n\boldsymbol\theta-\boldsymbol r(t)\right\|_2^2
+\lambda\left\|\boldsymbol\theta\right\|_2^2.
\]

该方法不限制退化方向，病态条件下可能在未退化部件上产生符号相反的补偿量，即 gas-path analysis 中的 smearing 现象。

### 3.5.2 硬约束参数化

对于无维修复位的 run-to-failure 退化，部件健康参数相对初始状态应满足

\[
\tilde\theta_j(t)\le0,\qquad
\tilde\theta_j(t+1)\le\tilde\theta_j(t).
\]

令 \(\boldsymbol d(t)\ge0\) 表示每个循环新增退化量，通过累积矩阵 Cum 重参数化为

\[
\tilde{\boldsymbol\theta}=-\boldsymbol{Cum}\boldsymbol d.
\]

从而得到

\[
\hat{\boldsymbol d}=
\arg\min_{\boldsymbol d\ge0}
\left\|\boldsymbol M\boldsymbol d-\boldsymbol r\right\|_2^2
+\lambda\left\|\boldsymbol{Cum}\boldsymbol d\right\|_2^2.
\]

该问题通过数据增广转化为非负最小二乘。非正和单调性由参数化恒等满足，不依赖人工设置软惩罚权重。

### 3.5.3 正则化参数标定

旧版实验表明，L-curve 与 Morozov 准则在硬约束压平的正则化路径上可能失效。因此，正式闭环不再要求在线无监督选择 lambda，而是在发动机单元隔离的 calibration 机队上，以 unit-balanced MSE 从预先固定的对数网格选择 lambda。每台发动机权重相同，避免长序列主导超参数。

L-curve、Morozov和无约束路径代理仍保留为病态反问题的机制分析，但不承担正式测试选参任务。

## 3.6 连续健康参数驱动的诊断闭环

### 3.6.1 故障检测与多部件隔离

归一化部件严重度定义为

\[
z_j(t)=\max\left(0,-\hat{\tilde\theta}_j(t)\right).
\]

部件阈值 \(\tau_j\) 取 calibration 健康周期严重度的 99% 分位数。若 \(z_j(t)>\tau_j\) 连续 K 个循环，则锁存该部件故障标签。K 从 \(\{1,2,3,5\}\) 中选择：首先满足 calibration FAR 不超过5%，随后最大化 macro-F1，若仍并列则选择更大的 K。发动机检测标签为九个部件标签的逻辑或。

多个部件可以同时退化，因此本章采用多标签隔离。评价指标包括逐部件 precision、recall、F1、macro/micro-F1 和 Hamming loss，不使用互斥多分类混淆矩阵替代多故障评价。

### 3.6.2 有序退化等级

数据集没有直接给出早期、中期和严重退化的工程标签。本章在 calibration 真值的活动部件归一化严重度上拟合三成分一维 Gaussian mixture model，并按成分均值排序为早期、中期和严重三个有序等级；健康状态单独记为0级。测试阶段直接将估计严重度输入锁定模型，不使用测试发动机寿命终点进行二次归一化。

该等级表示相对于训练机队退化分布的位置，不等同于 OEM 告警或适航阈值。正式结果同时报告两、三、四成分定义的敏感性；若结论不稳定，则不将离散等级作为主要贡献，而只保留连续严重度。

### 3.6.3 未知故障拒识

定义物理重构不一致度

\[
q(t)=\sqrt{\frac1{13}\left\|
\boldsymbol r(t)-\boldsymbol H_n\hat{\tilde{\boldsymbol\theta}}(t)
\right\|_2^2}.
\]

当观测残差不能由当前诊断字典解释时，q 应增大。拒识阈值由 calibration 已知样本确定。正式未知故障实验依次从诊断字典中移除 HPT、Fan、HPC、LPT 和 LPC 故障族，并将被移除故障族作为未知测试，形成五个 leave-one-fault-family-out 折。每一折均报告 AUROC、AUPRC、已知接受率和未知拒识率。

## 3.7 实验设计与评价指标

### 3.7.1 数据划分

DS01、DS04、DS05、DS06和DS07在文件内部按发动机unit划分为60%训练、20%标定和20%分布内测试。每个子集至少保留一台标定和一台测试发动机。DS02与DS03全部test单元只用于未见故障组合测试。划分清单固定保存于 `matlab/outputs/protocol/unit_split_manifest.csv`。

### 3.7.2 对比与消融

正式对比至少包含全零哨兵、无约束岭回归B、线性数据驱动回归和经过同等训练/标定的数据驱动时序模型。消融至少包含去除单调约束、去除符号约束、去除Tikhonov收缩以及改变前三循环基准长度。所有方法必须使用相同train/calibration/test_id单元。

### 3.7.3 统计原则

连续估计、检测隔离和阶段指标首先在每台发动机内部计算，再以发动机unit为重采样单位构造95% bootstrap区间。飞行循环不作为独立重复样本。正式实验至少运行5个数据划分/训练随机种子，并同时报告均值、标准差和不同随机种子下的最差结果。

## 3.8 实验结果

### 3.8.1 连续健康参数估计

主划分 calibration 从预先固定的十三点对数网格中选择了 \(\lambda=0.01\)。完整约束方法在 ID 与未见组合发动机上的 unit 平均 RMSE 分别为 0.0348 和 0.0465。五次 unit 划分所选 \(\lambda\) 分别为 0.01、0.316、0.001、1 和 31.623，表明标定最优点对机队划分较敏感；但主要诊断指标的跨划分波动明显小于 \(\lambda\) 本身的波动。因此，正文应把该现象解释为病态反问题下的标定不确定性，而不能只报告单次划分的最优参数。

九维参数的离散隔离结果显示，同一物理部件内效率与流量修正量仍存在明显混叠。连续参数估计用于说明退化方向和严重度，参数级离散标签暂不作为“九类均可靠隔离”的证据。影响矩阵条件数、奇异谱和弱右奇异向量仍应与旧版可辨识性图联合报告。

### 3.8.2 故障检测与多标签隔离

ID 测试的 unit 平均 FAR、DR 和 F1 分别为 0.086、0.906 和 0.924，其中 FAR 的 95% unit bootstrap 区间为 [0,0.259]。未见组合的 DR 为 1.000、F1 为 0.866，但 FAR 达到 0.552，其 95% 区间为 [0.453,0.644]。未见组合平均首次报警相对真实故障起点提前 14.6 个循环；由于故障前已经出现报警，该负延迟必须与高 FAR 一并解释，不能称为有利的提前预警。

ID 参数级 isolation macro-F1 为 0.415，五次划分均值为 0.481±0.116；未见组合分别为 0.672 和 0.647±0.088。主划分各参数 ID F1 约为 0.171—0.371，尚不足以支持九个健康参数均可可靠离散隔离的结论。下一版将保留九维连续估计，同时按 N-CMAPSS 的物理故障构造增加 HPT、Fan、HPC、LPT 和 LPC 五个部件族的主要隔离评价。

### 3.8.3 有序退化等级

三成分主定义下，ID weighted kappa 为 0.902、等级 MAE 为 0.221；未见组合分别为 0.732 和 0.457。五次划分中，ID kappa 为 0.904±0.021，未见组合为 0.855±0.075。预测等级逆转次数均为0，与不可逆单调参数化一致。

两、三、四成分定义下的排序一致性总体较高，但等级 MAE 随成分数变化，且主划分未见组合结果低于其余划分。因此这里只能称为“数据定义严重度的有序分层具有较好重复性”，不能把三阶段解释为唯一自然划分或工程安全阈值。

### 3.8.4 未见组合与未知故障

DS02/DS03 只包含字典内已知部件的新组合，属于组合泛化而非未知类别。leave-one-fault-family-out 结果中，Fan、HPC、LPT 和 LPC 四折在主划分上均得到 AUROC/AUPRC=1，但 HPT 折 AUROC=0、AUPRC=0.1、未知拒识率=0。五次划分中 HPT 未知拒识率始终为0，失败具有重复性。

由于每折未知测试发动机只有1—2台，且部分折的已知接受率仅为0.333—0.750，当前结果不足以支持普适开放集识别结论。更准确的表述是：物理重构不一致度能够拒绝四个成对参数故障族，但对单参数 HPT 故障缺乏可靠区分能力。

### 3.8.5 消融与鲁棒性

无约束 B 在 ID 和未见组合上的 unit 平均 RMSE 分别为 0.283 和 0.321，显著高于完整 D 的 0.0348 和 0.0465；未见组合检测 F1 和阶段 kappa 也分别由完整 D 的 0.866、0.732 降至 0.110、0.100，说明约束对病态反演具有实质作用。

然而，去除 Tikhonov 收缩后的 `D_no_shrink` 与完整 D 在检测和隔离上几乎相同，说明主划分 \(\lambda=0.01\) 时性能优势主要来自可行域结构，而非收缩强度。`sign_only` 在未见组合阶段 kappa 上高于完整 D，表明单调约束收益具有场景依赖性，不能笼统宣称所有指标均受益。

在 1 个标准差高斯噪声下，ID 检测 F1 仍为 0.916，但 isolation macro-F1 从 0.415 降至 0.301；未见组合 isolation macro-F1 从 0.672 降至 0.353。因此，鲁棒性结论应限定为“检测输出相对稳定，精细隔离对噪声更敏感”。

## 3.9 讨论

本章方法的优势在于连续部件健康参数、硬约束可解释性和对非活动部件补偿误差的抑制。其适用前提是退化过程不可逆且不存在维修复位。对于间歇故障、传感器故障或维护后健康状态恢复，应在变点位置重新初始化，或使用允许状态跳变的分段模型。

影响矩阵 H 在当前方法中被视为训练分布内的局部线性映射。若发动机型号、传感器布局或工作包线发生明显变化，应重新标定 H，不能假定其跨平台不变。N-CMAPSS 属于高保真合成数据，虽然具有真实飞行条件和多种部件退化模式，仍不能替代真实机队验证。

有序退化等级是为连接后续RUL预测而建立的状态抽象。其作用是提供可重复、可解释的严重度分层，而不是人为制造安全阈值。后续章节应优先使用连续健康参数及其不确定性，离散等级用于状态展示、样本分层和维护策略接口。

## 3.10 本章小结

本章构建了由相似修正、健康基准残差、量程归一化影响矩阵和非正—单调约束反演组成的部件健康估计方法，并在连续估计基础上建立故障检测、多部件隔离、有序退化等级和未知故障拒识。实验采用发动机单元完全隔离的训练、标定与测试协议，并将未见故障组合和未知故障作为两个不同泛化问题进行评价。正式结论将在完成闭环重跑、随机种子重复、消融与鲁棒性试验后依据锁定CSV填入。
