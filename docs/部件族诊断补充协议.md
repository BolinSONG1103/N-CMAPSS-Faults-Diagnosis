# 部件族诊断补充协议（v3，运行前冻结）

## 1. 修正动机

诊断闭环 v2 同时把九个连续健康参数当作九个离散故障标签。正式结果表明，同一物理部件的效率与流量修正量存在明显混叠，ID 参数级 macro-F1 较低。N-CMAPSS 的 Fan、HPC、LPT 和 LPC 退化模式由同一部件的效率与流量修正量共同描述；论文要回答的“故障分类”首先是故障部件，而不是强行区分同一部件内两个高度相关的连续参数。

因此，v3 不修改九维连续反演，只在其后增加与数据故障构造一致的五部件族诊断层。v2 的参数级结果和失败项永久保留，用于可辨识性分析。

## 2. 冻结映射

| 部件族 | 九维参数索引 | 连续参数 |
|---|---|---|
| HPT | 1 | HPT efficiency |
| Fan | 2,3 | Fan efficiency、Fan flow |
| HPC | 4,5 | HPC efficiency、HPC flow |
| LPT | 6,7 | LPT efficiency、LPT flow |
| LPC | 8,9 | LPC efficiency、LPC flow |

映射由数据变量与故障模式确定，不允许根据运行结果调整。

## 3. 部件族严重度与标签

对部件族 \(g\) 的参数集合 \(J_g\)，定义

\[
s_g(t)=\sqrt{\frac{1}{|J_g|}\sum_{j\in J_g}\max(0,-\hat\theta_j(t))^2}.
\]

九维健康参数已按训练数据量程归一化，因此族内采用均方根聚合；该定义避免双参数部件仅因维数更多而系统性获得更大的严重度。

真实部件族标签只由数据文件预先给定的活动故障参数集合映射得到。健康周期全部为0；退化周期允许多个部件族同时为1，因此仍是多标签任务。

## 4. 标定与测试隔离

1. 继续使用 v2 已锁定的九维连续估计和 lambda；不重新读取测试真值选参。
2. 五个族阈值分别取 calibration 健康周期族严重度的99%分位数。
3. 持续周期数仍从 {1,2,3,5} 中选择：先满足 calibration unit-balanced FAR≤5%，再最大化 family macro-F1，并列时取较大的 K。
4. test_id、DS02 和 DS03 只用于最终评价，不参与阈值或 K 的选择。
5. 本补充实验不修改 v2 的有序等级和未知故障协议，避免同时改变多个研究问题。

## 5. 预注册指标

- 检测：FAR、DR、precision、F1、首次检测延迟；
- 虚警事件：存在任一健康周期报警的发动机比例、首次故障前报警提前量；
- 隔离：五部件族逐族 precision、recall、F1、FAR，unit-balanced macro/micro-F1 与 Hamming loss；
- 统计：先逐发动机计算，再以发动机为 bootstrap 单位形成95%区间；
- 场景：test_id 与未见组合分别报告，禁止合并。

## 6. 结论门槛

- v3 与 v2 的标签空间不同，不直接用 macro-F1 数值宣称算法“提升百分之多少”；v3 用于检验离散目标是否与物理部件构造一致。
- 若某部件族 F1 仍低或未见组合 FAR 仍高，正文必须保留并讨论。
- 只有五个部件族在重复划分下均有稳定证据，才能把“部件级故障隔离”列为主要贡献；九维参数级分类不再作为进入门槛。

## 7. 科学依据边界

本补充协议沿用 N-CMAPSS 数据论文对部件退化参数和故障模式的定义，以及研究协议中列出的航空发动机气路健康参数文献。均方根只用于量程归一化参数的同部件聚合，不宣称是 OEM 工程告警量，也不改变影响矩阵 H 的数据辨识属性。
