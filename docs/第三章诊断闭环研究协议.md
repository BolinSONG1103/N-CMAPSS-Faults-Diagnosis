# 第三章诊断闭环研究协议

> 状态：实施前冻结协议。任何正式测试结果生成后，不得依据结果移动阈值、改变切分或删除失败项。

## 1. 研究问题与结论边界

本章研究对象是 N-CMAPSS 真实飞行工况下的合成涡扇发动机退化数据。方法首先从 13 维气路残差反演 9 维部件健康参数，再建立故障检测、多部件隔离、有序退化等级和未知故障拒识。闭环输出供后续 RUL 预测章节使用。

本章允许形成的结论是：

1. 相似修正、健康基准和部件影响矩阵可将变工况测量转化为部件级退化估计；
2. 非正、单调硬约束能够改善不可逆渐进退化条件下的估计稳定性和故障特异性；
3. 在发动机单元完全隔离的测试协议下，连续健康参数可支持正常/故障检测、多标签部件隔离和数据定义的有序退化等级；
4. 物理重构不一致度可用于拒绝未进入诊断字典的故障族，但必须通过留一故障族实验验证。

本章不作以下结论：

- 不把数据辨识的影响矩阵称为纯第一性原理模型；
- 不把数据定义的退化等级称为 OEM 安全阈值或适航阈值；
- 不把 N-CMAPSS 合成数据结果直接外推为真实发动机性能；
- 不声称当前不可逆单调模型适用于间歇故障或维修复位；
- 不用测试集真值选择正则化参数、诊断阈值、阶段模型或拒识阈值。

## 3. 数据隔离协议

### 3.1 单元级三划分

DS01、DS04、DS05、DS06、DS07 的 dev 发动机分别按文件内部的 unit 划分为：

- `train`：60%，用于健康基准、残差标准差、影响矩阵 H 和数据驱动对照训练；
- `calibration`：20%，用于选择 lambda、诊断阈值、持续周期数、退化等级模型和拒识阈值；
- `test_id`：20%，只用于分布内正式测试。

每个文件至少保留 1 台 calibration 和 1 台 test_id 发动机。划分由固定随机种子生成并写入 `unit_split_manifest.csv`。所有方法共用完全相同的 unit 划分。

DS02 与 DS03 的 test 单元只用于未见故障组合测试。任何形式的基准拟合、H 辨识、超参数选择和阈值标定均不得读取其真值。

### 3.2 防泄漏规则

1. 真值健康参数 T 只用于训练 H、训练数据驱动对照、calibration 选参和最终指标计算；
2. 测试阶段模型输入只包含 13 维残差及允许的 4 维工况量；
3. 每台发动机前三个 cycle 只用于该发动机的初始偏置校准，不用于跨发动机拟合；
4. 阶段模型不得使用测试发动机的终点退化量、寿命长度或未来 RUL；
5. 缓存必须记录 unit 划分签名，划分改变后旧缓存自动失效。

## 4. 闭环定义

### 4.1 连续健康参数

量程归一化健康参数记为 theta_j(t)。方法 D 通过 theta = -Cum*d、d >= 0 保证 theta 非正且不随时间恢复。部件严重度定义为：

`severity_j(t) = max(0, -theta_hat_j(t))`。

该量已经由训练数据的健康参数量程归一化，不再使用测试发动机终点归一化。

### 4.2 故障检测与多标签隔离

每个部件阈值 tau_j 取 calibration 健康周期估计严重度的 `(1-alpha)` 分位数。alpha 在实验前固定为 0.01。若某部件严重度连续 K 个 cycle 超过 tau_j，则输出该部件故障。K 只在 calibration 单元的候选集合 `{1,2,3,5}` 中选择，选择规则为：先满足 calibration FAR 不超过 5%，再最大化 macro-F1，仍并列时取较大的 K。

发动机故障检测为任一部件标签为真。由于多个部件可同时退化，隔离任务采用多标签而不是互斥多分类。

### 4.3 有序退化等级

N-CMAPSS 直接提供健康/退化状态和连续健康参数，不直接提供“早期/中期/严重”工程标签。因此本章定义的是数据驱动的有序退化等级：

- 0：健康；
- 1：早期退化；
- 2：中期退化；
- 3：严重退化。

对 calibration 单元中真实活动故障分量的归一化严重度拟合三成分一维 Gaussian mixture model。按成分均值从小到大排序后得到三个有序等级。测试时将估计严重度输入锁定的混合模型。发动机总体等级取所有活动部件等级的最大值。

该等级只说明相对于训练机队退化分布的位置。正式结果必须同时报告两成分、三成分、四成分的敏感性；若等级结论对成分数不稳定，则阶段分析降级为连续严重度分析。

### 4.4 未知故障拒识

物理重构不一致度定义为：

`q(t) = rms(r(t) - Hn*theta_hat(t))`。

拒识阈值取 calibration 已知工况/故障得分的 99% 分位数。未知故障实验采用 leave-one-fault-family-out：每次从诊断字典中移除一个故障族，用其余故障族标定阈值，再将被移除故障族作为未知测试。只报告 AUROC、AUPRC、已知接受率和未知拒识率；不把内部已见过的 DS02/DS03 组合称为未知类别。

## 5. 正则化参数

主结果不再依赖测试真值或事后 oracle。lambda 从预先固定的对数网格中，通过 calibration 发动机的 unit-balanced MSE 选择。每台发动机权重相同，不允许长序列占更大权重。选择完成后 lambda 对 test_id、DS02 和 DS03 全部锁定。

L-curve、Morozov 和 B 路径代理的失败结果保留为机制分析，但不再承担正式部署参数选择任务。

## 6. 正式指标

### 6.1 连续估计

- unit-balanced RMSE、MAE、技能分；
- 活动部件相关系数；
- 非活动部件估计幅值；
- 95% 发动机单元 bootstrap 区间。

### 6.2 检测与隔离

- 检测：FAR、DR、precision、recall、F1、首次检测延迟；
- 隔离：逐部件 precision/recall/F1、macro-F1、micro-F1、Hamming loss；
- 多标签结果不使用普通单一混淆矩阵冒充多故障分类。

### 6.3 退化等级

- 四等级混淆矩阵；
- macro-F1、加权 Cohen kappa、等级 MAE；
- 首次进入各等级的周期误差；
- 预测等级逆转次数。方法 D 理论上应为 0，仍需实际核查。

### 6.4 未知故障

- AUROC、AUPRC；
- 已知接受率、未知拒识率；
- 每个 leave-one-fault-family-out 折单独报告，禁止只给平均值。

所有置信区间以发动机 unit 为重采样单位。cycle 只用于时序指标，不当作独立重复样本。

## 8. 预注册阶段门

以下判据在正式测试前冻结：

1. 数据隔离：物理方法和所有对照均只能使用 train 单元拟合；不满足则全部测试无效；
2. 检测闭环：test_id 与未见组合分别报告，不能合并掩盖差异；
3. 阶段稳定性：三成分等级的 weighted kappa 必须同时报告 2/4 成分敏感性；
4. 未知拒识：每个留一故障族折均保留，失败折不得删除；
5. 重复性：至少 5 个 split/训练随机种子；HistGB 数值指纹只作为旧结果复现，不作为新协议跳过重复试验的理由；
6. 诚实性：任何指标未超过 Z_zero 或简单阈值基线，正文必须明确写出。
