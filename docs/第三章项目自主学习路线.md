# 第三章项目自主学习路线

目标不是记住代码，而是能够独立解释“每个变量为什么存在、每条约束改变了什么、每张图回答什么问题”。按以下顺序学习，每一步都要保留自己的手算或运行记录。

## 第一阶段：数据与物理量

1. 打开一个 N-CMAPSS HDF5 文件，只读取变量名和一台发动机；
2. 区分 A、W、X_s、T：辅助标签、工况、传感器、健康参数；
3. 画同一传感器在不同 TRA/Mach 下的原始值，说明为什么工况会掩盖退化；
4. 找出一个效率参数下降时受影响最明显的三个传感器，并说明方向是否稳定。

完成标准：能够不看代码解释 `unit`、`cycle`、`hs`、`TRA`、`theta_c`、`delta_c`、flow modifier 和 efficiency modifier。

## 第二阶段：健康基准与残差

重点阅读：

- `ncmapss_lib.add_corrected`
- `ncmapss_lib.build_pipeline` 的健康基准部分
- `health_baseline_py.m`

亲自完成：

1. 手算一个采样点的 `theta_c`、`delta_c`、修正转速和压力比；
2. 对一个传感器比较“实测值、健康基准预测、标准化残差”；
3. 解释为什么 Nf/Nc 不能作为健康基准输入；
4. 比较减去前三循环单元偏置前后的残差轨迹。

完成标准：能够解释健康基准不是故障分类器，而是在回答“相同工况下健康发动机应该测到什么”。

## 第三阶段：影响矩阵和病态反问题

先做一个三传感器、二健康参数的纸笔例子：

\[
r=H\theta.
\]

分别计算普通最小二乘、岭回归和非负最小二乘。然后改变 H 的两列，使其越来越接近，观察估计误差如何放大。

重点阅读：

- `ncmapss_lib.build_M`
- `ncmapss_lib.build_cum`
- `ncmapss_lib.solve_B`
- `ncmapss_lib.solve_D`

必须能推导：为什么 `theta=-Cum*d, d>=0` 同时保证非正和单调；为什么条件数高意味着不同部件容易相互补偿；为什么量程归一化会改变 lambda 的含义。

## 第四阶段：诊断闭环

重点阅读：

- `chapter3_diagnostic_lib.fit`
- `threshold_labels`
- `fit_stage_gmm`
- `reconstruction_score`
- `experiment_21_diagnostic_closure.m`

按一台发动机逐周期跟踪：

1. `theta_hat` 如何变成 severity；
2. severity 如何超过健康阈值；
3. 持续 K 个周期后何时锁存部件标签；
4. 多个部件标签如何形成发动机故障状态；
5. 严重度如何进入有序 GMM；
6. `r-H*theta_hat` 为什么可用于未知故障拒识。

完成标准：能够解释多故障为什么是多标签任务，以及DS02/DS03“未见组合”和留一故障族“未知故障”有什么区别。

## 第五阶段：实验设计与统计

逐行检查 `unit_split_manifest.csv`，确认同一发动机没有跨角色出现。自己回答：

- 为什么不能随机划分cycle或窗口？
- 为什么lambda和阈值可以使用calibration真值，但不能使用test真值？
- 为什么bootstrap要以unit而不是cycle重采样？
- 为什么单一随机种子不足以支撑论文结论？
- 为什么一张好看的单机轨迹不能替代机队统计？

## 第六阶段：论文与答辩

每张正文图写三句话：

1. 这张图检验哪个研究问题；
2. 图中哪一项数据支持或否定了假设；
3. 该图不能说明什么。

答辩前必须能独立回答：

1. 本章物理性到底来自哪里？
2. H 为什么不是纯物理模型？
3. 缺少 HPT flow 对结论有什么限制？
4. 单调约束在什么场景会失效？
5. lambda 如何在不看测试真值时确定？
6. 退化等级为什么不是安全阈值？
7. 未知故障为什么不能用DS02/DS03直接代替？
8. 数据驱动对照怎样保证公平？
9. N-CMAPSS结果为什么不能直接代表真实发动机？
10. 连续健康参数如何进入下一章RUL预测？

只有当上述问题能够脱离AI和代码独立回答，才算真正掌握本章。
