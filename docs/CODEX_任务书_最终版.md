## 1. 研究背景（你必须理解的最小上下文）

### 1.1 这一章在做什么
在 NASA **N-CMAPSS** 涡扇发动机数据集上做**部件级健康参数的定量估计**：
输入 13 维气路残差 r(t)（逐飞行循环），输出 9 维健康参数 θ(t)
（各部件效率/流量的退化百分比）。这是一个**病态线性反问题**
（影响系数矩阵 H_n 条件数 ≈1563），本章的方法是：

> **物理进结构，而不是物理进 loss**：
> H 的方向 = 数据驱动辨识的部件故障物理指纹（冻结）；
> 退化不可逆（θ≤0）与单调性（θ(t+1)≤θ(t)）通过重参数化 θ=−Cum·d, d≥0
> 变成**恒等满足的硬约束**，问题退化为 NNLS + Tikhonov 收缩。

### 1.2 差异化定位（写文稿时不许稀释）
- 参考论文（王昆博士论文第3章 DTAE）做的是故障**检测+隔离**（定性分类，
  输出"HPT 坏了"）；本章做的是**定量估计**（输出"HPT 效率降 1.8%"），
  θ̂(t) 是连续、有物理量纲的退化轨迹，可直接接入后续 RUL 预测章节。
- **为什么不用 PINN**（已论证并否决，文稿 1.2.4 节把它作为对照物）：
  N-CMAPSS 不提供部件特性图，气路热力学方程组闭不上；而单调/非正约束
  已经是硬约束（恒等满足），退回 PINN 的软惩罚是降级且引入不可选的权重。
- **为什么 MoE 不是硬塞的关键词**：实证发现 H 的方向随工况稳定
  （分档余弦 ≥0.9865）而幅值随 TRA 单调变化（最大 2.12 倍），
  自然数学形式就是 H(w)=H0·diag(g(w))，g(w)=Σα_k(w)·s_k 即软门控 MoE；
  手工 TRA 四分位分档就是它的硬门控特例。

### 1.3 本章的叙事骨架（文稿按这个写）
1. 约束的独立价值（逐点占优，不靠调参）；
2. **最有价值的负面发现**：约束压平正则化路径 → 三种经典 λ 选择准则
   （dev-argmin / L-curve / Morozov）同机制集体失效；
3. 解法：无约束对偶路径的代理标定（有理论依据：B/D 的 oracle λ 重合）；
4. 工况自适应 H(w)：整周期平均对工况天然免疫（机制），
   价值出现在分段窗口（工程常态）；
5. 与数据驱动端到端方法的对照：组合外推实验。

## 3. 【铁律】方法论纪律（每条都有踩坑史，不可协商）

1. **预注册判据**：每个实验的通过/失败判据在运行前写死并打印在输出开头，
   跑完只对照不挪线。案例：代理标定 DS02 loss=0.0389 vs 预注册 0.03，
   最终写法就是"未达标，以 0.009 之差"——不改成 0.04。
2. **全零哨兵 Z_zero**（θ̂≡0，技能分 S=0）出现在每张结果表。
   某方法某指标追不上哨兵 = 该指标下它没有真实信息，如实标注。
3. **数据切分只按发动机 unit 切**，绝不按样本随机切。
4. **零点 = 每台机最初 3 个 cycle 的均值**，不是"健康期均值"
   （健康期内 θ 已缓降，均值零点会让真值落到 θ≤0 可行域外——
   脚本14 因此把自己判了死刑）。**分段窗口下零点必须在同一段内算**
   （单元测试已演示：不修正会伪造 +0.556 的假偏移，修正后 +0.030）。
5. **健康基准 GBM 的自变量只有 `["TRA","Mach","theta_c","delta_c"]`**，
   绝不能加 Nf/Nc（转速被退化污染，逻辑循环）。任何门控/网络的工况输入
   严格等于这 4 维（否则开出"基准没吃掉、门控吃到了"的泄漏通道）。
6. **量程归一化**：H 列乘 THETA_SPAN 后条件数与 λ 才有物理意义。
7. **诚实报告**：判据挂了写挂了+机制分析。本章的负面发现
   （λ 准则集体失效机制）是全章最有价值的一节，这个基调不变。
8. **FAST_MODE 数字一律不进文稿**；每个脚本必须有 FAST_MODE 开关。
9. **先落盘后裁决**：逐点原始 CSV 在任何汇总/裁决/出图之前写盘
   （脚本18 曾在 json.dump 崩掉，靠提前落盘的 raw_scan.csv 保住全部计算）。
   json.dump 前对 pandas MultiIndex 先 `reset_index()`（元组 key 会抛
   TypeError——就是脚本18 那次崩溃的原因）。
10. 诊断评测时真值 θ 只用于计算指标，**绝不进任何模型输入**。

## 5. 【逐字一致】管线常量、七步流程与反演器

重构后以下内容只允许在共享库中存在一份：

```python

N_HEALTHY_ID, N_DEGRADED_ID = 60000, 150000

           "LPT_eff_mod","LPT_flow_mod","LPC_eff_mod","LPC_flow_mod"]
THETA_SPAN = {"fan_eff_mod":0.223446,"fan_flow_mod":0.121209,"LPC_eff_mod":0.118767,
              "HPC_flow_mod":0.070658,"LPC_flow_mod":0.046187,"LPT_eff_mod":0.036194,
              "LPT_flow_mod":0.032908,"HPC_eff_mod":0.025540,"HPT_eff_mod":0.018668}
LAM_MAIN = 31.6
```

七步管线（数值必须与现有脚本逐位一致）：
1. 读 5 个辨识子集：A_dev 拿 hs 分层行号（健康 6 万/退化 15 万，SEED=42），
   只读选中行；
2. 全局参考 T_ref/P_ref = 健康池 T2/P2 中位数；
3. 相似修正 → 13 通道：Nf_c=Nf/√θc、Nc_c 同、Wf_c=Wf/(δc√θc)、
   T24/T30/T48/T50 除 T2、P15/P21/P24/Ps30/P40/P50 除 P2；
4. 健康基准：13 个 HistGradientBoostingRegressor(max_iter=150, max_depth=6,
   random_state=42)，自变量只有 OP_COLS；
5. 残差 = 实测 − 基准预测，除以健康池残差 std（单位=σ）；
6. H 辨识：逐子集逐通道 LinearRegression(残差 ~ 该子集真值θ)，
   DS06 只取 LPC 两列（HPC 用 DS05 的）；H_n = H·diag(THETA_SPAN)；
7. 验收指纹：**cond(H_n) ≈ 1562.8**。重构后必须打印核对，偏差 >1% =
   管线被改坏。

反演器（三个全保留）：
- `solve_B(Hn,R,lam)`：Tikhonov 岭回归（无约束基线，逐 cycle 闭式解）。
- `solve_D(M,Cum,R,lam,T,n)`：本文方法。θ=−Cum·d 重参数化 →
  scipy.optimize.nnls（**不用 cvxpy**）；Tikhonov 用数据增广
  [M; √λ·Cum]；M/Cum 与 λ 无关，在 λ 循环外构造。
- `solve_D_var(...)`：逐 cycle 不同 H 的版本（H(w) 用）；
  设计矩阵 (t,i) 块 = −H_t（**下标是 t 不是 i**）。

窗口构造 `build_windows(df, unit, mode)`：
- mode="full"：每 cycle 随机抽 N 样本取均值；
- mode="highTRA"：每 cycle 只用 TRA ≥ 该 cycle 75 分位的样本
  （段内 <5 个样本则回退全周期并计数）；**零点同段**（铁律4）；
- 每 cycle 同时返回被抽中样本的 OP_COLS（H(w) 的 ḡ_t 必须在同一批样本上平均，
  数学上精确：cycle 内 θ 常数 + 模型对 θ 线性 ⇒ 等效矩阵 = H0·diag(ḡ_t)）。

指标：技能分 S = 1−MSE/MSE(全零)；早期段（前 30% cycle）用绝对 RMSE
（真值≈0 时技能分分母趋零）；虚警 = 6 个未退化部件 |θ̂| 均值；
检出 = 3 个真退化部件与真值的相关系数均值。
