# 诊断闭环正式结果审查

> 审查对象：闭环 v2 正式划分、五次 unit 重复划分、消融与鲁棒性结果。本文只记录由仓库 CSV/JSON 支持的结论，不把验证器通过等同于性能充分。

## 1. 协议与可复现性

- `verification.json` 已通过：5 个辨识文件共 30 条 unit 划分记录，train、calibration、test_id 按发动机隔离。
- 主实验为非烟测模式；lambda、部件阈值、持续周期数、阶段模型和拒识阈值均由 calibration 单元确定，测试真值未用于选择。
- 正式测试只有 5 台 ID 发动机和 9 台未见组合发动机。置信区间及重复划分必须与点估计同时报告，不能把 cycle 数量当作独立样本量。

## 2. 主实验能支持的结论

### 2.1 故障检测

| 场景 | DR | F1 | FAR | 95% unit bootstrap 区间（FAR） |
|---|---:|---:|---:|---:|
| ID 测试 | 0.906 | 0.924 | 0.086 | [0.000, 0.259] |
| 未见组合 | 1.000 | 0.866 | 0.552 | [0.453, 0.644] |

ID 检测达到较高召回率和 F1，但区间仍较宽；未见组合虽然全部故障周期被检出，健康周期虚警明显偏高。未见组合平均首次报警提前 14.6 个循环，本质上反映故障发生前已经出现报警，不能解释为有利的“提前预警”。

五次划分下，ID 检测 F1 为 0.934±0.027，FAR 为 0.168±0.131；未见组合 F1 为 0.901±0.028，FAR 为 0.363±0.158。由此只能称检测召回和 F1 对划分较稳定，不能称虚警受控或未见组合检测已经稳健。

### 2.2 参数级多标签隔离

主划分 ID isolation macro-F1 为 0.415，五次划分均值为 0.481±0.116。主划分九个参数的 ID F1 约为 0.171—0.371，说明九个效率/流量修正量尚不能作为九类均可靠的离散故障标签。

未见组合的 macro-F1 为 0.672，五次划分均值为 0.647±0.088。该结果主要来自 HPT、LPT efficiency 和 LPT flow 三个实际活动参数，不能外推为九维参数均具有同等隔离能力。

N-CMAPSS 故障模式在 Fan、HPC、LPT 和 LPC 上通常由同一物理部件的效率与流量修正量共同表征。因此，下一轮实验应在保留九维连续估计的同时，把五个物理部件族作为主要离散隔离目标；九维参数级结果保留为可辨识性分析。该改动属于诊断目标与数据故障构造的一致性修正，必须建立新版本实验并保留当前 v2 结果，不能覆盖或删除失败项。

### 2.3 有序退化等级

三成分主定义下，ID weighted kappa 为 0.902、MAE 为 0.221；未见组合 weighted kappa 为 0.732、MAE 为 0.457。五次划分均值分别为：ID kappa 0.904±0.021、MAE 0.211±0.041；未见组合 kappa 0.855±0.075、MAE 0.287±0.107。

等级顺序在不同划分中总体可重复，但 2/3/4 成分定义会改变 MAE，且主划分的未见组合结果明显低于其余划分。因此正文可表述为“数据定义的有序严重度具有较好的排序一致性”，但不可表述为工程告警等级或已经确定的三阶段自然边界。

### 2.4 未知故障拒识

主划分中 Fan、HPC、LPT、LPC 四折 AUROC/AUPRC 为 1，但 HPT 折 AUROC=0、AUPRC=0.1、未知拒识率=0。五次划分中 HPT 的未知拒识率始终为 0；其他四个故障族的未知拒识率均为 1。与此同时，部分折的已知接受率只有 0.333—0.750。

每折未知测试发动机仅 1—2 台，样本极小。因此当前结果只能说明物理重构不一致度对四个成对参数故障族有区分信号，但不能宣称形成了普适未知故障识别器。HPT 失败折必须在正文和图中保留。

## 3. 消融与鲁棒性能够支持的结论

- 完整约束 D 在 ID 上的 RMSE、检测 F1 和阶段 kappa 明显优于无约束 B；在未见组合上，无约束 B 的检测 F1 仅 0.110、阶段 kappa 仅 0.100，说明约束对病态反演具有实质作用。
- `D_no_shrink` 与完整 D 的检测和隔离结果几乎相同，主划分 lambda=0.01 时 Tikhonov 收缩贡献很小。不能把性能优势主要归因于收缩项。
- `sign_only` 在 ID 检测和阶段指标上弱于完整 D，但在未见组合阶段 kappa 上反而更高。单调约束的收益具有场景依赖性，应以配对 unit 统计而非单一平均数表述。
- 1σ 高斯噪声下，检测 F1 变化较小，但 ID isolation macro-F1 从 0.415 降至 0.301，未见组合从 0.672 降至 0.353。由此可称检测较稳健，不能笼统声称“诊断整体鲁棒”。
- 前 1/3/5 个参考循环的结果没有单调一致的最优值，说明参考长度影响有限但并非无影响；3 个循环只能作为冻结设置，不应宣传为数据证明的唯一最优值。

## 4. 超参数稳定性

五次划分均选择 K=5，但 lambda 分别为 0.01、0.316、0.001、1 和 31.623，跨越约 4.5 个数量级。性能总体比 lambda 数值稳定，说明部分划分的标定 MSE 路径较平坦或最优点不稳定。

正文应同时报告 lambda 的跨划分变化，并把它解释为病态反问题下标定不确定性，而不能只报告主划分的 0.01。下一版可增加“近最优集合”或标定曲线稳定性分析，但任何选择规则必须先在 calibration 上冻结，不能依据测试结果重新挑选。

## 5. 下一轮工作的进入条件

1. 保留当前 v2 全部正式失败项，建立独立的部件族隔离实验，不覆盖 v2 文件。
2. 五类部件族映射固定为 HPT={1}、Fan={2,3}、HPC={4,5}、LPT={6,7}、LPC={8,9}；映射来自数据故障构造，不允许根据结果调整。
3. 部件族阈值和持续周期数仍只能由 calibration 单元确定。
4. 增加“至少一次健康期误报警的发动机比例”和首次误报警周期，避免锁存标签下 cycle-FAR 被单一早期误报主导而缺少解释。
5. 未见组合虚警和 HPT 拒识失败在新方法中仍须报告；若没有改善，应收缩论文结论，而不是删除实验。

## 6. 依据边界

部件效率/流量健康参数、不可逆退化约束和 N-CMAPSS 故障模式的依据沿用研究协议中列出的 N-CMAPSS 数据论文及 NASA 约束健康估计研究。部件族诊断的引入只改变离散标签层级，不改变九维连续健康参数反演，也不把数据辨识矩阵 H 宣称为第一性原理模型。
