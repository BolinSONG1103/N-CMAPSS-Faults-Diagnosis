# 第3章结果审查与结论边界

> 本文对应当前双主线正稿。旧闭环 v2 的有序等级、未知拒识和九参数离散隔离结果仍保留在
> `matlab/outputs/` 与 git 历史中，但不再作为本章主线，也不混入当前 19 个图号。

## 1. 两条主线的评估协议

- 连续退化估计：训练、标定与测试按发动机 unit 完全隔离，考核跨新发动机泛化。
- DTAE 诊断：池化 dev 发动机后，每台按循环 70/30 划分且循环不重叠，考核已知机队的分布内在线诊断。
- 两者的指标不可直接互换，也不得把 DTAE 分布内结果表述为跨发动机隔离泛化。
- 所有图只读取锁定 CSV；测试真值不参与拟合、选参或阈值调整。

## 2. 连续退化估计能支持的结论

- 活动部件相关系数 0.996、原始百分比 RMSE 0.13%，代表发动机轨迹和多发动机误差图共同支持高精度趋势跟踪。
- 影响矩阵量程归一化条件数为 1562.8，反问题明显病态；非正—单调硬约束对抑制未退化部件补偿性虚警具有实质作用。
- 正则化参数存在欠收缩与过收缩两端风险，主工作点来自标定机队，不由测试集选择。
- H 为数据辨识的局部线性映射，不宣称跨型号、跨全包线或第一性原理普适性。

## 3. DTAE 主诊断能支持的结论

- 事件级检测率 1.000；锁定逐循环图数据中，健康循环虚警为 0.141、故障循环召回约 0.853。
- 四部件主诊断 5 seed 聚合 macro-F1 0.990、micro-F1 0.992；风扇、高压压气机、低压压气机、涡轮 F1 分别约为 1.000、0.996、0.966、0.996。
- DS06 的 HPC/LPC 非对角共现来自真实并发退化。多标签矩阵的非对角项既可能表示混叠，也可能表示并发标签，因此行和不要求等于 1。
- 这些结果支持已知机队在线诊断，不支持“新发动机无需标定即可同等分类”的结论。

## 4. HPT/LPT 可辨识性边界

- 由当前仓库 Hn 可复现计算，HPT 与 LPT 部件族子空间到其余部件组合子空间的最小主夹角均约为 0.53°。
- 五部件细分 macro-F1 0.917；HPT F1 0.865、LPT F1 0.760，HPT→LPT 与 LPT→HPT 共现率约为 5.0% 和 10.6%。
- 因此四部件（涡轮合并）作为工程主诊断，五部件结果用于解释涡轮内部细分边界。
- 此前文档出现的 8.3° 数值未能由当前锁定 Hn 与脚本复现，已从当前正文与图中撤下。

## 5. 鲁棒性边界

- 图3-19来自旧物理约束连续估计及统一决策层的锁定噪声/偏置/缺失通道压力测试。
- 该图可支持“连续估计与旧决策层在扰动下具有一定稳定性”的补充结论，不能标成 DTAE 鲁棒性。
- 当前仓库尚无独立、锁定的 DTAE 特征消融与多噪声级测试 CSV，因此正文不宣称这两项已经完成。

## 6. 图件完整性

- 当前清单共 19 个图号：17 张程序图、2 张手绘规格。
- 程序图均同时提供 600 dpi PNG 与矢量 PDF。
- `figure_pipeline/validate_outputs.py` 校验数量、文件配对、旧编号残留和最低文件完整性。
- R 正式脚本已落盘，但当前环境无 R，需在作者本地运行后检查中文字体和 cairo PDF 支持。

## 7. 外推边界

N-CMAPSS 为高保真合成数据。当前结论不直接外推真实机队、不同发动机型号或未覆盖工况包线；
真实部署前仍需独立外场数据验证、重新标定健康基准与影响矩阵，并由工程标准定义告警阈值。
