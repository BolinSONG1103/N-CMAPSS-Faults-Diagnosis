## 图件如何重建

正文图由 `../figure_pipeline/` 从 `../matlab/outputs/` 的锁定结果 CSV 生成：

```bash
cd ../figure_pipeline && python3 make_all.py
```

框架与算法结构图（图3-1、图3-10）由作者按 `figure_specs/` 手绘，程序不生成。

## 叙事主线（完整诊断闭环）

主线一：相似修正与健康基准残差 → 影响矩阵 → 约束反演 → 连续退化程度（跨发动机泛化）。

主线二：气路残差与物理时序特征 → DTAE → 故障检测 → 四部件主隔离（分布内在线诊断），
并以五部件细分解释 HPT/LPT 可辨识性边界。
