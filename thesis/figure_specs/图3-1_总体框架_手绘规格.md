## 一句话主题
用一张图讲清"离线辨识 → 在线诊断闭环"：从 13 维气路残差反演 9 维部件健康参数，
再由统一决策层形成**故障检测 → 部件族隔离 → 有序退化等级 → 未知故障拒识**的完整闭环。

## 版式：上下两大分区

### 上区（离线辨识，建议浅绿底色）
自左向右三条并列输入 + 汇聚：

1. **训练发动机数据**（圆柱体，标注"仅 train 单元，可见真值 θ"）
   → **相似参数修正**（圆角矩形：TRA / Mach / θc / δc）
   → **健康基准模型**（梯形，标注 HistGB；输入仅 4 维工况，**不含转速 Nf/Nc**）
   → **标准化气路残差 r = (x − x̂₀)/σ**（小方块，可嵌一段残差曲线示意）

2. 残差 r 与真值 θ 一起 → **影响矩阵辨识**（圆角矩形：线性回归得 H）
   → **量程归一化**（H·diag(span) = Hₙ，标注 cond(Hₙ)=1562.8）
   （此处可嵌入图3-2 的奇异值谱缩略，呼应病态性）

3. **标定发动机数据**（圆柱体，标注"calibration 单元"）
   → **决策层标定**（圆角矩形，列出：正则化 λ、部件阈值 τ、持续周期数 K、
   三成分退化等级 GMM、未知拒识阈值），强调"**测试真值不参与任何选择**"。

上区右侧汇出两条锁定产物箭头进入下区：**Hₙ / 残差尺度 σ** 与 **全部决策阈值**。

### 下区（在线诊断闭环，建议浅橙底色）
自左向右单链 + 末端四分支：

1. **测试发动机**（圆柱体，标注"test_id / DS02 / DS03；仅可见 W、X，不可见真值"）
   → 相似修正 + 健康基准（复用上区锁定模型）→ **在线残差 r(t)**

2. → **非正—单调约束反演**（醒目圆角矩形，写出核心式
   `θ̂ = −Cum·d̂,  d̂ = argmin_{d≥0} ‖M d − r‖² + λ‖Cum·d‖²`）
   → **连续健康参数 θ̂(t)**（小方块，可嵌图3-3 的退化轨迹缩略）

3. θ̂(t) → **诊断决策层**（大圆角矩形，内部四个并排小框，用四种语义色）：
   - **故障检测**（二分类：严重度超阈值持续 K 周期 → 发动机故障）
   - **部件族隔离**（多标签：HPT / Fan / HPC / LPT / LPC，五色）
   - **有序退化等级**（健康/早期/中期/严重，四色渐变）
   - **未知故障拒识**（物理重构不一致度 q > 阈值 → 拒识）

4. 决策层右侧汇出**三个输出分支**（对应王昆式"预测标签"蓝框）：
   - 连续估计分支：部件退化程度与趋势 θ̂(t)（供后续 RUL 章节）
   - 离散诊断分支：检测标签 / 部件族标签 / 退化等级
   - 未知拒识分支：已知接受 / 未知拒绝

## 需要在图上明确标注的三条"防泄漏"信息（体现学术严谨）
- 训练可见真值 T；标定只用于选参与定阈值；测试仅可见 W、X。
- 健康基准与门控输入均**不含转速**，避免"退化信息先进基准再被反演"的信息回路。
- H 为**数据辨识的物理结构映射**，非第一性原理模型；退化等级为**数据定义**，非适航阈值。

## 配色与图元建议（与正文程序图保持语义一致）
- 部件族语义色：HPT 红、Fan 绿、HPC 蓝、LPT 橙、LPC 紫。
- 退化等级：健康浅灰 → 早期黄 → 中期橙 → 严重红。
- 离线区浅绿底、在线区浅橙底；数据圆柱体、模型梯形/圆角矩形、锁定产物用锁形图标。
- 箭头区分"数据流"（实线）与"仅训练可见的真值流"（虚线）。
